# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and welcoming. Critique work, not people.
- No harassment, insults, or personal or political attacks.
- No publishing other people's private information.
- Assume good intent, and ask before assuming.

Maintainers may remove comments, commits, issues or contributors that break these rules.

To report a problem privately, use [GitHub's private reporting](https://github.com/CharlieJamesGwapo/claude-work-skills/security/advisories/new) or message a maintainer through their GitHub profile. Reports are kept confidential.
